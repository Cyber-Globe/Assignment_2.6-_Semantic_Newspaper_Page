# The Global Chronicle

A semantic newspaper page created for my **HTML Foundations — Assignment 2.6**. The page presents a fictional global news edition using native HTML structure and elements.

## Page contents

- Newspaper masthead with edition details and navigation
- Lead story about an international renewable-energy agreement
- World news and business articles
- Market data displayed in a table
- Trending-news list
- Publication links and copyright information in the footer

## HTML features

The page uses semantic elements including `header`, `nav`, `main`, `section`, `aside`, `article` and `footer`. It also uses a heading hierarchy, article metadata, links, an ordered list, and a table with header and body sections.

## View the page

Open `index.html` in a web browser. This is a static HTML page and does not require a build step or additional dependencies.
